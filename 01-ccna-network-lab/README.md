# CCNA Network Lab

## Overview

This project documents my practical networking labs while studying for the Cisco CCNA certification.

## Objectives

- Practice IPv4 addressing and subnetting.
- Configure VLANs and basic switching.
- Understand routing fundamentals.
- Test network connectivity and troubleshoot common issues.
- Document network configurations and results.

## Tools

- Cisco Packet Tracer
- Git and GitHub

## Project Structure

- `topology/` — Network topology files and diagrams.
- `configs/` — Example device configurations.
- `docs/` — Network documentation and addressing plans.
- `evidence/` — Screenshots of tests and results.

## Progress

Currently building the initial network topology.

## Disclaimer

This is an educational lab. All configurations and test results will be documented as they are completed.
